# Isla Marinduque — Tourism & Cultural Innovation

A responsive single-page frontend prototype for the Tourism & Cultural Innovation sector, aligned with the scope of Marinduque State University's Hands-on Laboratory Activity #4.

## Project concept

- **Sector:** Tourism & Cultural Innovation
- **Local challenge:** Visitors may have difficulty finding an engaging, community-minded starting point for learning about Marinduque's natural attractions and living cultural heritage.
- **Target users:** Local and prospective visitors, students, and community tourism advocates.
- **Proposed solution:** A single-page island discovery site that presents tourism themes, cultural context, and a simple trip-planning checklist.
- **Core features:** (1) Responsive destination/culture/experience sections, (2) interactive trip checklist with progress and reset, (3) mobile navigation.

## Files

- `index.html` — semantic page content
- `styles.css` — responsive visual design
- `script.js` — mobile navigation and checklist interactions
- `prompt-log.md` — prompt experiment templates and documentation guidance
- `outputs/` — placeholder instructions for saving actual Copilot results

## Run locally

Open `index.html` in a browser. No backend, database, authentication, build step, or API is required. Google Fonts and illustrative photos use external URLs and therefore need an internet connection; the page layout and core checklist logic are local.
